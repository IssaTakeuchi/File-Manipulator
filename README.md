# File-Manipulator
##recursion バックエンドプロジェクト1 File Manipulator

コマンドラインから起動。

以下のコマンドを用意し、それぞれのファイル操作は説明の通り。

`python3 file_manipulator.py reverse inputfile outputfile`
inputfileの内容を逆にした新しいファイルを生成する。

`python3 file_manipulator.py copy inputfile outputfile`
inputfileをコピーし、outputfileとして生成する。

`python3 file_manipulator.py duplicate-contents inputfile outputfile`
inputfileの内容を読み込み、その内容を複製し、複製された内容をinputfileに n 回複製します。
